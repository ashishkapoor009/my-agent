name: SMED Quick Changeover Optimization
description: Use when the user wants to reduce equipment changeover or setup time, implement Single-Minute Exchange of Die (SMED), or minimize batch transition losses.

Procedure:
1. Stage 0 - Baseline Changeover Assessment:
   - Identify current changeover duration from last good part of Product A to first good part of Product B at full production speed.
2. Stage 1 - Separate Internal vs External Setup Activities:
   - External Setup: Activities that CAN be done while the machine is still running (fetching tooling, pre-heating dies, retrieving raw material, staging paperwork).
   - Internal Setup: Activities that can ONLY be done while the machine is stopped (bolting down dies, dismounting tooling, connection of airlines/cables).
   - Rule: Stoppage must not occur until all external setup is complete.
3. Stage 2 - Convert Internal Activities to External:
   - Pre-heat dies or barrels offline before machine stoppage.
   - Use pre-set standard tool carts with preset tool heights.
   - Standardize clamping heights and use intermediate fixtures or magnetic die platens.
4. Stage 3 - Streamline All Aspects of Remaining Internal Activities:
   - Eliminate threaded bolts: replace with 1-turn clamps, slotted holes, quick-release pneumatic couplings, or U-washers.
   - Implement parallel operations (two-technician choreographed pit-stop approach).
   - Eliminate adjustments: use fixed stops, mechanical locator pins, calibrated digital gauges instead of trial-and-error tweaking.
5. Stage 4 - Standardize External Setup:
   - Implement shadow boards, designated staging carts, and standard work checklist for pre-setup staging.
6. Format your final response with:
   - SMED STAGE BREAKDOWN: Current State vs Future Target
   - INTERNAL vs EXTERNAL CLASSIFICATION TABLE: [Activity | Current State | SMED Action | New State]
   - CHOREOGRAPHED "PIT-STOP" ACTION PLAN: Prioritized quick-win changes and expected reduction %.
