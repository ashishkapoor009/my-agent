name: DMAIC Project Charter Builder
description: Use when the user wants to initiate a Lean Six Sigma or Continuous Improvement project, define a DMAIC charter, establish baseline metrics, or formalize project scope and financial goals.

Procedure:
1. Business Case:
   - Why does this project matter to the business right now? Tie to strategic priorities (Safety, Quality, Delivery, Cost, Morale).
2. Problem Statement (5W2H format):
   - What is wrong, where did it occur, when did it start, how much (baseline magnitude), and what is the current trend?
   - Never include implied causes or solutions in the problem statement.
3. Goal Statement (SMART criteria):
   - Specific, Measurable, Attainable, Relevant, Time-bound.
   - Example: "Reduce defective PPM from 2,400 to below 250 by Q3 2026, saving $120,000 annually."
4. Project Scope Boundaries:
   - In-Scope: Clearly defined process start step and end step.
   - Out-of-Scope: Explicitly excluded machines, lines, geographic sites, or legacy systems.
5. Key Performance Metrics:
   - Primary Metric (Y): Direct measure of project success (e.g., First Pass Yield %).
   - Secondary / Consequential Metrics (Check): Metrics that must NOT degrade (e.g., cycle time, safety incidents).
6. Financial & Operational Impact:
   - Hard cost savings (scrap, overtime reduction), soft savings (capacity freed up), customer satisfaction.
7. Project Milestones & Team:
   - Champion / Sponsor, Value Stream Leader, Green/Black Belt, Process Owner, Finance Validator.
   - Phase gate target dates (Define, Measure, Analyze, Improve, Control).
8. Format your final response with:
   - DMAIC PROJECT CHARTER SUMMARY TABLE
   - PROBLEM STATEMENT vs GOAL STATEMENT
   - SCOPE ENVELOPE (In-Scope / Out-of-Scope)
   - METRICS & EXPECTED ANNUAL BENEFIT
